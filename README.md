# Important Dates Tracker – сервис учёта важных дат

## Назначение

Important Dates Tracker – приложение для учёта важных дат и напоминаний о них.

Приложение позволяет:

* просматривать напоминания в браузере;
* просматривать информацию о конкретном напоминании;
* просматривать список событий в браузере;
* проверять, какие напоминания пора показать;
* добавлять напоминания;
* отменять напоминания;
* добавлять события;
* просматривать активные напоминания;
* хранить данные между запусками приложения.

## Используемые технологии

* Python 3;
* Django 5.2 – веб-фреймворк;
* HTML – разметка веб-страниц;
* CSS и Bootstrap 5.3 – оформление страниц;
* pytest – автоматизированные тесты;
* flake8 – проверка качества кода.

## Целевая аудитория

Пользователи, которым необходимо помнить о днях рождения, годовщинах, профессиональных праздниках и других значимых датах.

## Предметная область

Основными объектами предметной области являются:
* напоминание;
* событие;
* категория;
* пользователь.

Напоминание связывает событие и пользователя и хранит срок, за который нужно напомнить.
Одно событие может иметь несколько напоминаний от разных пользователей.
Отменённое напоминание не блокирует создание нового напоминания для этого же события.

## Основные сущности

### Reminder – напоминание

Объект `Reminder` представляет напоминание о событии.

Основные атрибуты:
* `id` – уникальный идентификатор напоминания;
* `event` – объект `Event`;
* `user` – объект `User`;
* `remind_before` – за сколько дней напомнить;
* `is_sent` – признак отправки напоминания;
* `is_active` – признак активности напоминания.

Основные методы:
* `days_left()` – количество дней до события;
* `is_due()` – проверка, пора ли показать напоминание;
* `cancel()` – отмена напоминания;
* `mark_sent()` – отметить напоминание отправленным;
* `matches()` – поиск по названию события;
* `from_data()` – создание объекта `Reminder` из набора данных;
* `validate_remind_before()` – проверка корректности срока;
* `__str__()` – строковое представление напоминания.

### Event – событие

Объект `Event` представляет важную дату.

Основные атрибуты:
* `id` – уникальный идентификатор события;
* `title` – название события;
* `event_date` – дата события;
* `category` – объект `Category`;
* `user` – объект `User`;
* `is_recurring` – признак ежегодного события.

Основные методы:
* `days_until()` – количество дней до события;
* `matches()` – поиск по названию;
* `validate_title()` – проверка корректности названия;
* `__str__()` – строковое представление события.

### Category – категория

Объект `Category` представляет категорию событий.

Основные атрибуты:
* `id` – уникальный идентификатор категории;
* `name` – название категории.

Основные методы:
* `matches()` – поиск по названию;
* `__str__()` – строковое представление категории.

### User – пользователь

Объект `User` представляет пользователя системы.

Основные атрибуты:
* `id` – уникальный идентификатор пользователя;
* `name` – имя пользователя;
* `email` – адрес электронной почты.

Основные методы:
* `__str__()` – строковое представление пользователя;
* `from_data()` – создание объекта `User` из набора данных.

## Страницы веб-интерфейса

* `/` – главная страница: описание приложения и навигация (view-функция `index()`);
* `/reminders/` – список напоминаний: объекты `Reminder` из `data/reminders.json` (view-функция `reminders()`);
* `/reminders/<int:reminder_id>/` – страница напоминания (view-функция `reminder_detail()`);
* `/events/` – список событий: объекты `Event` из `data/events.json` (view-функция `events()`).

Если напоминание с указанным идентификатором не найдено, соответствующая страница возвращает код статуса 404.

## Основные операции

### Используется в веб-интерфейсе (ПР5)

* просмотр списка напоминаний;
* просмотр информации о напоминании;
* просмотр состояния и срока напоминания;
* просмотр списка событий.

### Отложено до следующих работ

Эти операции реализованы в ПР3 и работают в консольной версии. В веб-интерфейсе они появятся, когда будут добавлены формы и POST-запросы:

* создание напоминания;
* отмена напоминания;
* добавление события;
* поиск напоминания по названию события;
* фильтрация по активным напоминаниям;
* поиск пользователя.

## Хранение данных

Данные приложения хранятся в JSON-файлах:
* `data/reminders.json`;
* `data/events.json`;
* `data/categories.json`;
* `data/users.json`.

При загрузке данные из JSON преобразуются в объекты `Reminder`, `Event`, `Category` и `User`.
При сохранении объекты преобразуются в данные JSON.

Для связи напоминания с событием и пользователем в `reminders.json` используются их идентификаторы `event_id` и `user_id`.
Для связи события с категорией и пользователем в `events.json` используются идентификаторы `category_id` и `user_id`.

## Назначение модулей

### `main.py`

Консольная версия приложения (сохранена с ПР3). Отвечает за:
* запуск консольного приложения;
* отображение меню;
* получение данных от пользователя;
* организацию пользовательских сценариев.

### `config/`

Пакет настроек Django-проекта:
* `settings.py` – настройки проекта;
* `urls.py` – маршрутизация верхнего уровня;
* `asgi.py`, `wsgi.py` – точки взаимодействия с сервером.

### `homepage/`

Django-приложение, отвечающее за главную страницу:
* `views.py` – функция page() (общий HTML-каркас), view-функция index() и обработчик 404 page_not_found();
* `urls.py` – маршрут главной страницы.
Функция `page()` размещена здесь, потому что главная страница задаёт общий вид всех остальных страниц – она точка входа в проект. Остальные приложения импортируют её.

### `reminders/`

Django-приложение, отвечающее за напоминания:
* `views.py` – view-функции `reminders()` и `reminder_detail()`;
* `urls.py` – маршруты приложения;
* `models.py` – Django-модели (заполняется в следующих работах).

### `events/`

Django-приложение, отвечающее за события:
* `views.py` – view-функция `events()`;
* `urls.py` – маршруты приложения;
* `models.py` – Django-модели (заполняется в следующих работах).

### `models/`

Классы предметной области и функции работы с ними (пакет ПР3):
* `categories.py` – класс `Category` и функции работы с категориями;
* `events.py` – класс `Event` и функции работы с событиями;
* `reminders.py` – класс `Reminder` и функции работы с напоминаниями;
* `users.py` – класс `User` и функции работы с пользователями.

### `storage.py`

Отвечает за загрузку и сохранение данных. Выполняет преобразование:
* JSON -> объекты Python;
* объекты Python -> JSON.

### `utils.py`

Содержит вспомогательные функции консольного ввода:
* `input_int()` – безопасный ввод целого числа;
* `input_date()` – безопасный ввод даты.

### `tests/`

Содержит автоматизированные тесты проекта.
