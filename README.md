# Important Dates Tracker – сервис учёта важных дат

## Назначение

Important Dates Tracker – консольное приложение для учёта важных дат и напоминаний о них.

Приложение позволяет:

* просматривать события;
* находить события по названию;
* фильтровать события по категориям;
* сортировать события по дате;
* проверять предстоящие события и число дней до них;
* создавать напоминания;
* отменять напоминания;
* просматривать список напоминаний;
* добавлять новые события;
* удалять события;
* хранить данные между запусками приложения.

## Целевая аудитория
Пользователи, которым необходимо помнить о днях рождения, годовщинах, профессиональных праздниках и других значимых датах.

## Предметная область

Основными объектами предметной области являются:
* событие;
* категория;
* пользователь;
* напоминание.

Пользователь создаёт события, каждое событие относится к определённой категории.
Для события можно задать напоминание за определённое количество дней до наступления.
Одно событие может иметь несколько напоминаний.
Напоминание связано с конкретным событием и перестаёт быть активным после отмены.

## Основные сущности

### Event – событие
Объект `Event` представляет важную дату пользователя.
Основные атрибуты:
* `id` – уникальный идентификатор события;
* `title` – название события;
* `event_date` – дата события в формате ISO;
* `category` – объект `Category`;
* `user` – объект `User`;
* `is_recurring` – признак ежегодного события.
Основные методы:
* `days_until()` – количество дней до события;
* `matches()` – проверка совпадения названия с запросом;
* `validate_title()` – статическая проверка корректности названия;
* `__str__()` – строковое представление события.

### Category – категория
Объект `Category` представляет категорию событий.
Основные атрибуты:
* `id` – уникальный идентификатор категории;
* `name` – название категории.
Основные методы:
* `matches()` – проверка совпадения названия с запросом;
* `__str__()` – строковое представление категории.

### User – пользователь
Объект `User` представляет пользователя системы.
Основные атрибуты:
* `id` – уникальный идентификатор пользователя;
* `name` – имя пользователя;
* `email` – адрес электронной почты.
Основные методы:
* `__str__()` – строковое представление пользователя;
* `from_data()` – создание объекта `User` из набора данных.

### Reminder – напоминание
Объект `Reminder` представляет напоминание о событии.
Основные атрибуты:
* `id` – уникальный идентификатор напоминания;
* `event` – объект `Event`;
* `remind_before` – за сколько дней напомнить;
* `is_sent` – признак отправки напоминания.
Основные методы:
* `is_due()` – проверка, пора ли показать напоминание;
* `mark_sent()` – отметить напоминание отправленным;
* `__str__()` – строковое представление напоминания.

## Основные операции
### Работа с событиями
* добавление события;
* поиск события по названию;
* фильтрация событий по категориям;
* сортировка событий по дате;
* просмотр списка событий;
* удаление события.
### Работа с пользователями
* создание пользователя;
* поиск пользователя;
* просмотр информации о пользователе.
### Работа с напоминаниями
* создание напоминания;
* проверка срока напоминания;
* отмена напоминания;
* просмотр списка напоминаний.

При создании напоминания проверяется наличие связанного события.
Отменённое напоминание не блокирует создание нового напоминания для этого же события.

## Хранение данных
Данные приложения хранятся в JSON-файлах:
* `data/events.json`;
* `data/categories.json`;
* `data/users.json`;
* `data/reminders.json`.

При загрузке данные из JSON преобразуются в объекты `Event`, `Category`, `User` и `Reminder`.
При сохранении объекты преобразуются в данные JSON.
Для связи события с категорией и пользователем в `events.json` используются их идентификаторы `category_id` и `user_id`.
Для связи напоминания с событием в `reminders.json` используется идентификатор `event_id`.

## Назначение модулей
### `main.py`

Точка входа в приложение. Отвечает за:
* запуск приложения;
* отображение меню;
* получение данных от пользователя;
* организацию пользовательских сценариев.

### `models/events.py`
Содержит класс `Event` и функции работы с событиями.

### `models/categories.py`
Содержит класс `Category` и функции работы с категориями.

### `models/users.py`
Содержит класс `User` и функции работы с пользователями.

### `models/reminders.py`
Содержит класс `Reminder` и функции работы с напоминаниями.

### `storage.py`
Отвечает за загрузку и сохранение данных. Выполняет преобразование:
* JSON -> объекты Python;
* объекты Python -> JSON.

### `utils.py`
Содержит вспомогательные функции:
* `input_int()` – безопасный ввод целого числа;
* `input_date()` – безопасный ввод даты.

### `tests/`
Содержит автоматизированные тесты проекта.

## Запуск приложения
Для запуска приложения выполнить:

```text
python main.py
```
После запуска отображается главное меню.

## Тестирование
Для запуска автоматизированных тестов выполнить:
```text
pytest -v
```
Тесты проверяют:
* создание и работу объектов Event, Category, User и Reminder;
* методы классов;
* операции с событиями;
* создание и отмену напоминаний;
* связь события с категорией и пользователем;
* правила работы с датами.
